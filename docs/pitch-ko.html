시청자는 이미 플레이하고 있다 — 댓글로

  • 디네임의 쇼츠는 모두 시청자 상품이 걸린 게임: 다이아 찾기, 욕심 게임, 텔레파시, 용암 탈출
  • 최근 쇼츠 50개 조회수 중앙값 약 170만 (최고 550만) — 최근 업로드는 더 적어서 모델은 30만–80만으로 계획
  • 채널 문구: "구독하고 게임에 참여하세요!" — 하지만 지금은 보기만 할 수 있다
  • 한국 어린이·청소년 (추정; 공개된 인구통계 없음) → 폰, 교실, 친구 모임
YouTube 수치, 2026-11-06 기준

왜 지금인가

  • 한국 초4–고3 학생의 49.1%가 숏폼을 매일 시청 (2022년 0.2%). 온라인 동영상 하루 평균 200분
  • 한국 숏폼 이용자의 93.4%가 YouTube Shorts 이용
  • YouTube 라이브에 미니게임 추가(2025년 9월) — 하지만 크리에이터만 플레이. 블록 파티에서는 모든 시청자가 자기 폰으로 플레이
한국언론진흥재단 2025 청소년 미디어 이용 조사 (Korea Times, 2026-01-07) · 한국콘텐츠진흥원 2025 콘텐츠 이용 실태 조사 · TechCrunch 2025-09-16

플레이 방법

  • 호스트 화면에 코드 + QR
  • 방 하나에 폰 200대 테스트 완료
  • 7라운드 × 12–15초, 서버가 시간 관리
  • 텔레파시 · 욕심 게임 · 다이아 찾기 · 블록 텔레파시 · ㄹ 말하지 않기 · 용암
  • 주간 시즌 TOP 10 · 오늘의 챌린지 · 스폰서 배너 (참가 무료)

최고 인기 쇼츠를 게임으로: "ㄹ 말하지 않기"

한 단어 입력 · 모든 음절 안의 ㄹ 검사 (라, 를, 닭) · 어린이 안전 금칙어 · 진행자가 어떤 단어든 무효 처리 가능

큰 화면 + 폰

선순환: 게임 → 영상 → 게임

  • 디네임 버전 (/?creator=dname): 한국어 우선, "디네임 파이널" 브랜드 로비
  • 녹화 모드 (/?overlay=1): 디네임이 매주 시청자와 "디네임 파이널"을 녹화 → 다음 쇼츠로 (라이브도 가능)
  • 파이널이 다음 쇼츠가 된다: 클릭 한 번으로 9:16 요약 영상 생성 (라운드 하이라이트 + 시상대) → 새 플레이어 유입 → 다음 주 파이널
  • 오늘의 챌린지: 매일 모두에게 같은 5라운드, 오늘의 참가자들과 점수 비교, 결과 공유 . 시청자가 언제 보든 참여
  • 교실·친구 방이 업로드 사이에도 게임을 살려 둔다

크리에이터가 소개해도 버티도록

  • Cloudflare 엣지: 방마다 Durable Object 하나, 휴면 WebSocket, 알람 타이머
  • 부하 테스트: 폰 200대, 전체 에피소드 — 답변→공개 p50 ≈ 0.2초
  • 상태 페이지 (5분 간격 점검) + 이메일 알림 · 매시간 실제 서비스에서 전체 에피소드 테스트
  • 버전별 배포 + 명령 한 번으로 롤백 · 매일 리더보드 백업
  • 어린이 방송 안전: 닉네임 필터 (영어/한국어), 계정 없음, 채팅 없음
  • 단위·엔드투엔드·브라우저 UI·오버레이 테스트
